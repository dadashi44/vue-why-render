Расширение Vue Why Render показывает, какие компоненты перерисовываются, почему и как
часто, не выходя из VS Code. Приложение передаёт данные расширению по локальному
WebSocket.

## Что оно делает

- **Дерево компонентов**: панель в боковой колонке со списком отслеживаемых компонентов, отсортированным по числу рендеров.
- **Зависимости**: реактивные источники (ref, пропсы, сторы) и компоненты, которые их используют.
- **CodeLens**: число рендеров и средняя длительность над компонентами в `.vue`-файлах.
- **Строка состояния**: общее число рендеров и число горячих компонентов.
- **Команды**: подключить, отключить, поставить на паузу, продолжить и сбросить сканер из палитры команд.

## Подключение

1. Установите расширение.
2. Включите мост в приложении опцией `vscode`:

```ts
import { scan } from 'vue-why-render'

scan(app, {
    vscode: true,        // подключиться к VS Code на порту 7710
    // vscode: { port: 8080, host: 'localhost' }  // свой порт и хост
})
```

3. Расширение запускает WebSocket-сервер на порту 7710 и ждёт, пока приложение подключится.
   Со стороны браузера переподключение идёт само каждые 3 секунды, поэтому порядок запуска
   приложения и VS Code не важен.

## Настройки

| Настройка | По умолчанию | Описание |
| --- | --- | --- |
| `vueWhyRender.port` | `7710` | Порт WebSocket |
| `vueWhyRender.autoConnect` | `true` | Начинать слушать при активации |

Если меняете порт, поменяйте его и в приложении: `vscode: { port }`.

## Команды

| Команда | Описание |
| --- | --- |
| `Why Render: Connect to App` | Запустить WebSocket-сервер |
| `Why Render: Disconnect` | Остановить сервер |
| `Why Render: Pause Scanner` | Приостановить сбор данных |
| `Why Render: Resume Scanner` | Возобновить сбор данных |
| `Why Render: Reset Counters` | Сбросить все счётчики рендеров |

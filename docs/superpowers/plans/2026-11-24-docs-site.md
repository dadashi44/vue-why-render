# Документация на Astro + Starlight — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Документация vue-why-render на `vue-why-render.js.org/docs/` на трёх языках с меню и поиском; README сокращается до введения и ссылок.

**Architecture:** Отдельный пакет `docs-site/` (Astro 7 + Starlight 0.43, `@astrojs/vue`), собирается после Vite-лендинга в `dist-site/docs`. Контент — Markdown-страницы, перенесённые из трёх README; меню и проверка полноты переводов строятся из одного списка страниц.

**Tech Stack:** Astro 7.4, @astrojs/starlight 0.43, @astrojs/vue 7, starlight-links-validator 0.27, Pagefind (встроен в Starlight), node:test.

**Spec:** `docs/superpowers/specs/2026-11-24-docs-site-design.md`

## Global Constraints

- Astro 7 требует Node ≥ 22.23.4. Локально все команды `docs-site` выполнять с `PATH=$HOME/.nvm/versions/node/v22.23.4/bin:$PATH`; системный Node 20 их не запустит. В `docs-site/package.json` — `"engines": { "node": ">=22.23.4" }` и `docs-site/.nvmrc` с `22.23.4`.
- Адреса: английский — `/docs/<slug>/`, русский — `/docs/ru/<slug>/`, китайский — `/docs/zh-cn/<slug>/`. Главная документации (`/docs/`) — страница «Введение».
- `base` = `${SITE_BASE}docs` (без завершающего слэша; `SITE_BASE` по умолчанию `/`), `site: 'https://vue-why-render.js.org'`, `outDir: '../dist-site/docs'`.
- `/` (лендинг) и `/cases/bigplay/` после сборки на месте и не меняются.
- Цвета: фон `#0d0f13`, текст `#e6e8ec`, приглушённый `#949aa6`, акцент `#6ee7a8`; шрифт текста `ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`, моноширинный `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`. Тёмная тема по умолчанию, переключатель светлой темы остаётся.
- Без градиентов, эмодзи, карточек-«фич» и прочего шаблонного оформления.
- Зависимости Astro только в `docs-site/package.json`; корневой `package.json` получает только скрипты.
- Тексты страниц — перенос из `README.md` (en), `docs/README.ru.md` (ru), `docs/README.zh-CN.md` (zh). Перевод с английского только для: `concepts/wasm`, `more/comparison`, `more/faq`, `guides/vscode` (ru и zh). Терминологию переводов брать из соответствующего README того же языка.
- Коммиты без `Co-Authored-By`, без упоминаний ассистента и «Generated with Claude Code».

## Список страниц (единый для всех задач)

Источник правды — `docs-site/src/pages-list.mjs`: экспорт `sections` — массив `{ label: {en, ru, 'zh-CN'}, items: [{ slug, label: {en, ru, 'zh-CN'} }] }`. Из него строится меню (`astro.config.mjs`) и проверка в тесте. Слаги:

| Раздел | Слаги |
|---|---|
| Начало | `index` (Введение), `start/installation`, `start/vue`, `start/nuxt`, `start/manual` |
| Руководства | `guides/panel`, `guides/devtools`, `guides/pinia`, `guides/router`, `guides/hints`, `guides/reports`, `guides/tests`, `guides/budgets`, `guides/editor`, `guides/mcp`, `guides/vscode` |
| Как это работает | `concepts/reason`, `concepts/cost`, `concepts/wasm` |
| Справочник | `reference/options`, `reference/api`, `reference/test-api` |
| Ещё | `more/comparison`, `more/faq`, `more/limitations`, `more/cases`, `more/contributing` |

Каждая задача добавляет в `pages-list.mjs` только свои страницы — меню всегда ссылается на существующие.

## Review Focus

- Страница есть на английском, но забыта на русском/китайском → Starlight тихо показывает английский текст. Тест `every page exists in every locale` в Task 1 проверяет это для всего списка.
- Ссылка внутри страницы ведёт на несуществующий слаг (или на `#якорь` из README, которого больше нет) → `starlight-links-validator` роняет сборку (Task 1 его подключает; каждая следующая задача обязана собрать без ошибок).
- Сборка с `SITE_BASE=/vue-why-render/` (github.io) → ссылки и ассеты под `/vue-why-render/docs/`. Тест `respects SITE_BASE` в Task 1.
- Лендинг стёрт сборкой документации (`emptyOutDir`) → тест `landing and case page survive` в Task 1.
- Переключатель языков на странице ведёт на ту же страницу другого языка, а не на главную → обеспечивается одинаковыми слагами; проверяется тестом полноты в Task 1.

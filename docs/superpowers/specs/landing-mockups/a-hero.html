See which components re-render, and why.

A dev-only Vue plugin. Each render gets an outline on the page and one line that names its cause: the prop, ref, computed, store or route that changed.

Five kinds of cause, named plainly

Vue knows why a component updated. vue-why-render keeps that answer and shows it next to the render, with the value before and after.

propProductCard price: 1290 → 1190
refSearchBar query: "lam" → "lamp"
computedClock time (from now: ref)
piniaCartBadge cart.items.length: 2 → 3
routerProductPage params.id: /p/12 → /p/13

Your AI agent can read it too

vue-why-render-mcp hands the live report to Claude Code, Cursor or any MCP client, so the agent sees the render causes instead of guessing.

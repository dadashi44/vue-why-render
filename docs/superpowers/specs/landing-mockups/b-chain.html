Every re-render has a cause. Read it.

vue-why-render follows the change from the line that made it to the component that redrew, and prints the whole path.

On the page

Outlines flash on each render. A panel lists the components that render most, with the cause of every update.

In your tests

expectRenders(CartBadge)
  .toBeAtMost(1)

In CI and with agents

Render budgets fail the build. The MCP server lets Claude Code or Cursor read the same report you see.

Two lines to try it

Install it as a dev dependency and register it only in development. Production builds stay untouched.

npm i -D vue-why-render

// main.ts
if (import.meta.env.DEV) app.use(WhyRender)

# Changelog

## [0.1.2] — 2026-09-16

### Исправлено

- Пакет ломал прод-сборку приложения. Единственная голая ссылка на `process.env.NODE_ENV` заставляла `@rollup/plugin-commonjs` считать наш ESM-бандл смешанным CommonJS, и его переписывание выдавало синтаксически битый код — сборка Nuxt падала с `Unexpected token &&` внутри нашего файла. Теперь режим читается через `globalThis.process`, голой ссылки в бандле нет.

### Изменено

- Сканер по умолчанию включён везде, кроме явно опознанного прода. В браузерном бандле `process` недоступен, поэтому угадать режим оттуда нельзя — гасить сканер в проде должен вызывающий код (`if (!import.meta.dev) return` в Nuxt, см. README).
- Убрано предупреждение в консоль про неопределённый режим: определять больше нечего.

## [0.1.1] — 2026-09-16

### Исправлено

- Сбор причин ронял приложение, которое сканируешь: поиск имени рефа перечислял `setupState` и тем самым вычислял computed'ы приложения прямо внутри `renderTriggered`. Найдено прогоном на реальном проекте — падала гидрация. Теперь свойства читаются через дескрипторы, геттеры не трогаются.
- Ошибка внутри хуков сканера больше не всплывает как ошибка рендера чужого компонента: хуки обёрнуты, о сбое сообщается один раз в консоль.
- Компоненты из файлов `index.vue` больше не называются «index» — берётся имя каталога: `navbar/index.vue` показывается как `navbar`.

## [0.1.0] — 2026-09-16

### Добавлено

- Определение причины перерисовки через `renderTriggered`: проп, реф, ключ стора, индекс массива, значения до и после.
- Диф пропсов между обновлениями с пометкой «новая ссылка, значение то же».
- Оверлей с рамками, цвет которых зависит от частоты перерисовок.
- Панель в shadow DOM: топ по количеству, топ по времени, дерево компонентов, лента событий, фильтр, пауза, сброс.
- Открытие SFC в IDE по клику через дев-сервер.
- Публичный API: `scan()`, `getStats()`, `getEvents()`, `onRender`.
